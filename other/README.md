## 7. Рефералы (avadrop.html, под инвентарём)
- У каждого аккаунта код из 5 цифр (создаётся автоматически, для старых аккаунтов при выполнении SQL).
- Ввести код другого человека можно один раз, менять нельзя. Свой код и код того, кто уже ваш реферал, ввести нельзя.
- Реферер получает 7% от прибыли реферала: выигрыш рулетки (минус цена платной крутки), чистый выигрыш ракеты (выплата минус ставка), итог «Енотов», если он положительный. Убытки бонус не уменьшают, у реферала ничего не вычитается.
- Доля: SQL, функция _ref_bonus (число 0.07). Бонус зачисляется целыми сотыми, остаток копится.
- Нужно заново выполнить SUPABASE-ACCOUNTS.sql.

## 9. Кулдаун «Енотов»
- Между играми 10 минут (считается от конца игры). SQL: функция _wh_cooldown() (interval '10 minutes'). Проверка на сервере, в клиенте показывается таймер на кнопке.
- Гостевое демо кулдауном не ограничено.
- Нужно заново выполнить SUPABASE-ACCOUNTS.sql.

## 11. Бонус за реферальный код
- Тот, кто вводит чужой реферальный код, один раз получает +0.67 б. SQL: функция ref_set, строка с _credit(a.id, 0.67, ...). Пригласивший за ввод ничего не получает, только 7% с прибыли.
