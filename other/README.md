- Видео легендарки с прозрачным фоном: CONFIG.legendaryVideo (WebM VP9 с альфой), для Safari - legendaryVideoFallback (HEVC .mov с альфой). Нет видео - играет анимация взрыва.
## 6. Игра «Ударь енота» (avadrop.html, после самолёта)
- Картинки: **img/raccoon.png** (енот, замените на свой PNG с прозрачным фоном) и img/avakyan-face.png (Авакян).
- Правила (SQL, блок «ЕНОТЫ»): +0.01 за енота (2-4 за ход), с шансом 40% (функция _wh_cells) вылезают Авакяны, клик по ним -1.00.
  Авакянов 1 на ходах 1-3, 2 на ходах 4-6, ... до 8. Время хода: 1.7 с, каждый ход x0.94, минимум 0.55 с (функция _wh_ms).
- Вывести баллы можно после 5-го хода (в SQL g.turn < 5 и в JS/whack.js MIN_CASH_TURNS). Итог может быть отрицательным, баланс уходит в минус (ограничение balance >= 0 убрано).
- Бросили игру (нет ответа дольше хода + 20 с): плюс сгорает, минус списывается.
- Гости: демо-игра в браузере, баллы не начисляются.
- Нужно заново выполнить SUPABASE-ACCOUNTS.sql.

## 7. Рефералы (avadrop.html, под инвентарём)
- У каждого аккаунта код из 5 цифр (создаётся автоматически, для старых аккаунтов при выполнении SQL).
- Ввести код другого человека можно один раз, менять нельзя. Свой код и код того, кто уже ваш реферал, ввести нельзя.
- Реферер получает 7% от прибыли реферала: выигрыш рулетки (минус цена платной крутки), чистый выигрыш ракеты (выплата минус ставка), итог «Енотов», если он положительный. Убытки бонус не уменьшают, у реферала ничего не вычитается.
- Доля: SQL, функция _ref_bonus (число 0.07). Бонус зачисляется целыми сотыми, остаток копится.
- Нужно заново выполнить SUPABASE-ACCOUNTS.sql.

## 8. Длительность раунда «Енотов»
- Начальная и минимальная длительность: SQL, функция _wh_ms: greatest(550, round(1700 * power(0.94, p_turn))) - 550 минимум (мс), 1700 старт (мс), 0.94 на сколько сжимается каждый ход. То же в JS/whack.js, функция demoMs (для демо).
- Появление и уход енотов в раунд не входят: JS/whack.js APPEAR_MS (появление), PAUSE_MS (уход), скорость анимации - CSS .wh-pop, transition: bottom 0.3s.

## 9. Кулдаун «Енотов»
- Между играми 10 минут (считается от конца игры). SQL: функция _wh_cooldown() (interval '10 minutes'). Проверка на сервере, в клиенте показывается таймер на кнопке.
- Гостевое демо кулдауном не ограничено.
- Нужно заново выполнить SUPABASE-ACCOUNTS.sql.
